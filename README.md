# Arabic Sentiment MLOps

End-to-end MLOps project for Arabic e-commerce sentiment analysis.

## Project Goal

Classify Arabic product reviews into:
- Positive
- Negative
- Neutral

## MLOps Stack

- PyTorch
- AraBERT
- FastAPI
- Docker
- MLflow
- DVC
- GitHub Actions
- BentoML
- Locust
- TensorRT
- ONNX
- Evidently
- Prometheus
- Grafana

## Status

Project initialization in progress.
